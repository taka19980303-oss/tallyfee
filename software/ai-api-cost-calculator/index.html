What this calculator does not include

Long-context surcharges. Some models charge more once a prompt passes a size threshold (Claude Haiku 5.5's over-100K tier is listed as its own row). The calculator does not switch tiers automatically.

Cache WRITE charges. The calculator prices cache reads. Writing to the cache costs extra — OpenAI and Anthropic publish separate write rates, listed on their pages here.

Gemini cache storage and grounding. Context-cache storage is $0.50 per 1M tokens per hour; search grounding is free for the first 5,000 requests a month, then $14 per 1,000.

Regional uplifts. OpenAI regional endpoints add 10% and Anthropic's US-only inference is 1.1x — both are opt-in, so neither is in the base math.
