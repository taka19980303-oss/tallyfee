Anthropic API pricing — every model's rates

Anthropic bills per token (MTok) with the most explicit cache pricing of the three: cache writes cost 1.25x (5-minute) or 2x (1-hour) the input rate, cache reads are a tenth or less, and the Batch API takes a flat 50% off — all printed in its official table. Below is the full published rate structure — every model, read on Anthropic's official pricing page on November 24, 2026.

Frequently asked questions

What is the cheapest current Anthropic API model?

At the reference workload (100,000 requests/mo averaging 1,500 input and 500 output tokens, 40% of input cached) it is Claude Haiku 5.5 at $34.60/month. Re-rank at your own numbers in the AI API cost calculator.

Does the Anthropic API have a batch discount?

Batch API is 50% off input and output (stated in the official pricing table); the batch discount also applies on top of cache rates.
