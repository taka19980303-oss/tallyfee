Google Gemini API pricing — every model's rates

Google bills the Gemini API per token with context caching priced separately (a read rate plus an hourly storage charge). Selected models are free within rate limits on the Free Tier; the flagship Gemini 4 models are not. Google also prints its scheduled increases on the pricing page itself — two are already announced below. Below is the full published rate structure — every model, read on Google Gemini's official pricing page on November 24, 2026.

Batch and background discounts

Batch API is 50% off (stated on the official pricing page). Flex is the same rate; Priority costs more.

Frequently asked questions

What is the cheapest current Google Gemini API model?

At the reference workload (100,000 requests/mo averaging 1,500 input and 500 output tokens, 40% of input cached) it is Gemini 3.8 Flash at $259.50/month. Re-rank at your own numbers in the AI API cost calculator.

Does the Google Gemini API have a batch discount?

Batch API is 50% off (stated on the official pricing page). Flex is the same rate; Priority costs more.
