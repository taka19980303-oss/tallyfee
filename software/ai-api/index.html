AI API pricing, compared by the token

The OpenAI, Claude and Gemini APIs all bill per token, but their rate cards are built differently. This hub lines up input, cached-input and output rates, batch discounts and already-announced increases, read on each provider's official pricing page. The reference workload is 100,000 requests a month averaging 1,500 input and 500 output tokens, with 40% of input served from cache.

✓ Prices verifiedNovember 24, 2026 — every price on this page was read on the vendor's official pricing page. Promotional prices are never used as the list price.
