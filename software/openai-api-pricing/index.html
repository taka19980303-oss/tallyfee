OpenAI API pricing — every model's rates

OpenAI bills per token, split into input, cached input and output, with cache writes charged separately by retention window. Its published page lists Standard short-context rates; Batch API rates are not published there, so this site shows them as not published rather than guessing a discount. Below is the full published rate structure — every model, read on OpenAI's official pricing page on November 24, 2026.
