AI API pricing explained — tokens, caching and batch discounts

An AI API bill is not priced per request; it is priced by the token mix inside each request. Here is where to look on a rate card, where the discounts hide, and what the headline rates leave out — using the verified rates on this site.

✓ Prices verifiedNovember 24, 2026 — every price on this page was read on the vendor's official pricing page. Promotional prices are never used as the list price.

The basic formula

Monthly cost = (uncached input × input rate) + (cached input × cached rate) + (output × output rate), with rates per 1M tokens. At 100,000 requests a month averaging 1,500 input and 500 output tokens with 40% of input cached, that is 150M input tokens (60M of them cached) and 50M output tokens. On those numbers GPT-6.2 Sol costs $686 a month and Claude Haiku 5.5 costs $34.60 — reproduce it in the calculator.

Output costs 5x input

On every model verified for this site, the output rate is exactly five times the input rate. What drives your bill is therefore answer length more than prompt length. Keeping responses short by design — capped summaries, structured output — is a direct cost control.

Cache reads are nearly free — writes are not

Reading input from cache costs 5–10% of the fresh input rate (GPT-6.2 Sol: $2.00 → $0.10). Putting your system prompt and shared context behind the cache removes most of the input bill. But writing to the cache is a separate charge: Anthropic charges 1.25x input for a 5-minute write and 2x for 1-hour, and OpenAI publishes its own write rates by retention window. Never budget a workload as if every token were billed at the read rate.

Batch is half price — where it is published

Anthropic and Google both print a flat 50% Batch API discount on their official pages. OpenAI's official pricing page did not show batch rates in this check, so in this site's calculator OpenAI models show "—" in Batch mode and sit out the verdict. We do not fill in a discount by guessing.

Some increases are already announced

Google prints future rates on the pricing page itself: Gemini 4 Carbon and Argon double on December 1, 2026 (input $2.00 → $4.00), and Gemini 3.8 Flash doubles on January 1, 2027. Budget a year at today's rates and the bill quietly doubles mid-year. The comparison hub shows the post-change monthly cost alongside the current one.

What headline rates leave out

Long-context tiers that raise rates past a prompt-size threshold, Gemini's cache storage charge ($0.50 per 1M tokens per hour), search grounding (free for 5,000 requests a month, then $14 per 1,000), and regional uplifts (OpenAI +10%, Anthropic US-only inference 1.1x). Each is a pay-if-you-use-it line that belongs in a budget next to — not inside — the per-token comparison.
