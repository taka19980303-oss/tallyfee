Anthropic APIの料金 — 全モデルの単価表

Anthropicはトークン（MTok）単位の課金で、3社の中でキャッシュ料金がいちばん明示的です：キャッシュ書き込みは入力の1.25倍（5分）／2倍（1時間）、読み取りは10分の1以下、Batch APIは一律50%オフ — すべて公式の表に印刷されています。 以下は公開されている単価の全構造です — 全モデルを、2026年11月24日にAnthropicの公式料金ページで読み取りました。
