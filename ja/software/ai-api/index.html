AI APIの料金を、トークン単価で比較

OpenAI・Claude・GeminiのAPIはすべてトークン単位の課金ですが、単価表の作りは3社で違います。ここでは入力・キャッシュ入力・出力の単価、バッチ割引、告知済みの値上げを、各社の公式料金ページで読み取って横並びにします。基準ワークロードは月10万リクエスト・平均入力1,500トークン・平均出力500トークン・入力の40%がキャッシュです。
