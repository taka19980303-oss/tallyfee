この計算機に入れていないもの

長コンテキストの追加料金。プロンプトが一定量を超えると単価が上がるモデルがあります（Claude Haiku 5.5の100K超ティアは独立した行として掲載）。ティアの自動切り替えはしません。

キャッシュ書き込み料。計算機が価格づけるのはキャッシュの読み取りです。書き込みは別料金で、OpenAIとAnthropicが公式に単価を公開しています（各プロバイダーのページに掲載）。

Geminiのキャッシュ保管料とグラウンディング料金。コンテキストキャッシュの保管は100万トークンあたり$0.50/時間、検索グラウンディングは月5,000リクエストまで無料・以降1,000件あたり$14です。

地域処理の上乗せ。OpenAIのリージョナルエンドポイントは+10%、Anthropicの米国限定推論は1.1倍 — どちらも任意の上乗せなので基本計算には入れていません。
