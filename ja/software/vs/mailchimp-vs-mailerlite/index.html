Mailchimp vs MailerLite：本当の価格差

連絡先5,000件では、Mailchimpの最安プランは月額$39.21（Essentials、月額課金）、MailerLiteは月額$44.10（Comfort、年額課金）です。 ただし定価は半分だけの話 — 2つのツールは連絡先の数え方が違い、リストが育つにつれて請求が変わります。

✓ 価格確認済み2026年11月23日 — このページの価格はすべてベンダーの公式料金ページで読み取ったものです。プロモーション価格を定価として使うことはありません。

損益分岐点：表のどのリスト規模でも、定価では同じツールが安いままです — となると決め手は、連絡先の数え方と段階を超えたときの扱いです（以下）。

数え方の違い

Mailchimp：オーディエンス内のすべての連絡先を数えます — 配信停止済み・未購読の連絡先も、アーカイブするまでは含まれます。請求は、請求期間中の連絡先数のピーク（最大値）が基準です。

MailerLite：有効な購読者のみを数えます — ただし請求サイクル内の累積です：サイクル中に一度でも有効だったアドレスは、あとで削除してもカウントされます。

上限を超えたら

Mailchimp：プランの上限を超えると、追加の連絡先ブロックが自動で課金されます（例：10,000件の段階ではEssentialsで1,000件ブロックあたり$22）。配信が止まることはありません。

MailerLite：連絡先ごとの料金はありません。段階を超えると次の段階へ自動アップグレードされ、カードに請求されます（まずアカウント内に警告が出ます）。
