広告について：本ページにはアフィリエイトリンク（広告）が含まれます。リンク先の公式サイトで申込みや購入が行われた場合、本サイトの運営者が紹介料を受け取ることがあります。紹介料の有無や金額によって、掲載する価格・順位・比較結果が変わることはありません。掲載する価格はすべて各社の公式ページで確認し、確認日を明記しています。
ホーム›ソフトウェア料金

ソフトウェアの本当のコスト

小規模事業者の請求書は、マーケットプレイスの手数料だけではありません。もう半分はソフトウェア — 連絡先ごとに課金するメール配信ツールと、席ごとに課金するCRMです。このセクションはそちらも同じやり方で合算します：実際の価格を、各ベンダーの公式料金ページで読み取り、確認日を明記します。

✓ 価格確認済み2026年11月23日 — このページの価格はすべてベンダーの公式料金ページで読み取ったものです。プロモーション価格を定価として使うことはありません。

メール配信

6つのツールを、3つの違う物差しで料金比較：連絡先課金、購読者課金、そしてBrevoの送信数課金。見出しの価格が全てではありません。

メール配信コスト計算機
リストの規模を入れると、6ツールすべての月額・年額・3年総額が安い順に出ます。
メール配信ツール比較
連絡先1,000 / 5,000 / 25,000件での価格を横並びに — 各ツールの「連絡先」の数え方の違いも。

CRM

席課金は、最低席数・導入費用・席の種類が出てくるまで単純に見えます。米ドルで価格を公開する5つのCRMと、地域別価格のmonday.com、あわせて6つのCRM。

CRMコスト計算機
チームの人数を入れると、HubSpotの必須導入費用まで含めた席課金の合計が出ます。
CRM比較
1席・5席・10席で年いくらか — 罠（最低席数、全従業員ライセンス、従量課金）がどこにあるかも。

AI API

OpenAI・Claude・GeminiのAPIをトークン単価で比較 — 入力・キャッシュ入力・出力の単価、バッチ割引、そして告知済みの値上げまで、すべて各社の公式料金ページで読み取りました。

AI APIコスト計算機
月間リクエスト数と平均トークン数を入れると、全モデルの月額がStandard／Batchモードで安い順に出ます。
AI API料金比較
3社のトークン単価を横並びに — Googleがすでに告知した値上げの日付もあわせて。

ここでも「確認済み＋確認日」が大事な理由

ソフトウェアの料金ページは動き続けています：MailerLiteは2026年6月に両プランの名前を変え、Brevoは「Business」プラン名をやめ、ActiveCampaignは2025年11月に連絡先の数え方を変え、HubSpotは確認したその日に自社ページ間でStarterの価格が2通りありました。このセクションの数字はすべて出典と確認日つきで、ベンダーが公開していないもの — ActiveCampaignの月額課金の価格など — は推測せず「公開されていない」と明記します。
