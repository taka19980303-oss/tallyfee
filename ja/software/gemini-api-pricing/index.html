Google Gemini APIの料金 — 全モデルの単価表

GoogleのGemini APIはトークン単位の課金で、コンテキストキャッシュは別料金（読み取り単価＋時間単位の保管料）。Free Tierでは対象モデルがレート制限内で無料ですが、フラッグシップのGemini 4は対象外です。値上げの予定も公式ページ自体に印刷されていて、すでに2件が告知されています。 以下は公開されている単価の全構造です — 全モデルを、2026年11月24日にGoogle Geminiの公式料金ページで読み取りました。
